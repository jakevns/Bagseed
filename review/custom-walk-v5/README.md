# Complete wardrobe side-stride rollout

All 15 tops, five bottoms and four shoes use eight distinct right-facing poses and matching left-facing bodies, across all 300 outfit combinations. Front/back walking remains four poses. The creator, wardrobe mirror and gameplay use direction-specific counts at 125 ms per side pose. Standing art, reactions, heads and saved outfit identifiers retain their existing paths.

Twenty-one missing garment sheets and one four-cell arm correction sheet were created with the built-in image generation tool. Original images, exact prompts and references are retained in `graphics/production/walk/wardrobe-v5/assets` and `sources/generation-v5.json`. Existing approved hoodie, jeans, sneakers and underlayer art is reused. The symmetric garment bodies are mirrored for the left view; the head renderer supplies the original left-facing head and facial features. Generated sources are registered with a single uniform similarity transform and original alpha. No limb warps or painted replacement garment pixels are used.

The previous automatic palm assignment swapped anatomical arms in poses 2 and 8. The shared rig now traces the actual near hand. Registration checks measure neck/near-palm fit, support-foot baseline and limb-core overlap. A tailored suit pose has an explicit manual visual review for its different silhouette. The complete compositor boards were inspected for garment seams, moving hems, exposed legs and shoe silhouettes.

`index.html` plays every garment at native 288 × 432 artwork resolution, with pause, slow motion and individual poses. `group-*.png` contains all eight side poses of each garment through the actual compositor. `live-wardrobe-validation.json` records the all-combination checks, hand connectivity, ground contact, flashlight following, build/presentation variants, save/reload and previews. `live-game-checks.json` records direct local-file game checks.

Rebuild registrations with `python graphics/production/walk/wardrobe-v5/sources/register.py`, then `node graphics/production/sources/build.cjs`. Run `node --test --test-concurrency=1 tests/custom-walk.test.cjs tests/custom-stride-live.test.cjs` with the browser environment configured as for the other game tests. The separate diagnostic capture script accepts pending registrations for visual inspection; production builds require every item to pass registration/review and source/atlas checksums.

Arm-layer correction: affected side shirts now retain their complete painted upper body and both arms together above bottoms. The cardigan's second contact pose is redrawn to reverse the first arm swing. See `../arm-v6/index.html` for synchronized before/after playback and pixel-level validation. Crop/tank and front/back artwork remain unchanged.
