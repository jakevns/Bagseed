# Custom character and leg rendering repair

The custom renderer combined undersized independent trousers with trousers and shoes left in the top artwork. This produced thin legs, mismatched ankles and duplicate footwear. Walking also split complete drawings into rectangular leg sections, which broke overlapping profile legs. The repaired compositor registers trousers to torso width, removes the old lower layers and draws the selected footwear once. Generic movement transforms one connected figure instead of cutting the legs apart.

The default player now uses the same modular face/body path as customized players, so outfit changes do not switch between two different illustrated faces. Custom portraits use 39 retained source-resolution components instead of enlarging small world sprites; no source character artwork was regenerated. Colored hair keeps its shading without the previous scattered black interior pixels. Long hair continues behind the shoulders rather than exposing a straight head-crop edge.

`before-after.png` compares the old and repaired clothing/color combinations. `customization-check.png` includes all four directions at enlarged and actual world size, portraits, and a named NPC reference. `creator.png` and `street.png` come from the actual browser creation/wardrobe/save test. `checkpoint.json` records the game checksum and completed validation.

Validation: 14 browser tests, 1,872 full-roster comparisons, 260 exact action-asset checks and 1,200 clothing/footwear combinations passed. The test creates a character through visible controls, changes clothes and details in the wardrobe, saves, reloads and verifies the rendered appearance in every direction. Existing save loading, customization choices, movement, scenes, seating, shops, flashlights, live smell encounters and emulated phone layouts passed. All 71 NPC standing drawings/regular portraits and all 52 integrated reaction sets are preserved. Pose progress remains 52 complete, 20 remaining.

Generic walking now uses a gentle connected sway/bob; this repair does not author new full walk cycles. Remy, Doug, Priya and Poppy retain their original drawn walking frames. The standalone playable result is `public/index.html`. No live user saves were used and no GitHub push or deployment was performed.

Rebuild the portrait components with `python graphics/production/sources/prepare-customization.py` before `node graphics/production/sources/build.cjs`. `npm run build:graphics` includes that preparation step. The preparation verifies the retained source checksums. The builder writes the game through a temporary file so a failed write cannot leave a partially written game.

Run `node tools/check.mjs`, `node --test --test-concurrency=1 tests/*.test.cjs` and `node tools/verify-action-batch.cjs`. For the exact pre-repair comparison retained during this session, run `node tools/verify-action-batch.cjs artifacts/custom-fix/before.html --renderer-fix`. The comparison tool recognizes the rendering revision, keeps strict assertions for preserved authored art, and treats the player/custom render changes as intentional when comparing with old builds. Set `BAGSEED_BROWSER_PATH` to the installed Chrome/Chromium executable on Windows.
