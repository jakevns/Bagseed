# Grow-light artwork and atmospheric lighting — approved production update

Four current catalog items are covered as one small batch: Lumi-Brite PRO ULTRA 9000 ($29.99), SunBlaster 42 ($119), Halcyon Q-Board 150 ($239), Verdant Arc 4-Bar ($449). Existing wattage, growth effects, heat, failure behavior, prices and fitting restrictions are unchanged. This covers grow equipment in the Lighting category; household decorative lamps are outside this batch.

assets/lights-atlas.png is the original generated on/off fixture sheet, retained unchanged. sources/manifest.json records SHA-256, dimensions, crop rectangles, native drawing bounds and tier-specific falloff parameters. The four fixtures progress from a small cream/red-blue diode housing through a charcoal panel and silver quantum board to four separate LED bars. Store, delivery and equipment icons use the same on-state art. Off/flicker states use the corresponding unlit crop.

sources/renderer.js is compiled into public/index.html by tools/compile-grow-lights.cjs. The fingerprinted external WebP is a lossless, byte-verified RGBA copy of the original atlas and is included in startup readiness, preventing an old-art flash. It replaces Gear.light and light-only drawGearIcon calls, provides cached smooth Gaussian falloff fields for the starter/2×2/4×4/5×5, and draws sparse deterministic dust below each emitting surface. The field grows wider with distance; budget tiers retain lavender tones while higher tiers use warm full-spectrum light. Twin 5×5 fixtures produce two overlapping soft spreads. No rectangular cutoff or stepped triangular beam is painted.

The tent contents pass registers field placement. Emission and airborne light are composited after the room's ambient tint, clipped to the illustrated opening and current zipper opening, with actual foreground character alpha cut out. This keeps the LEDs visibly on at night without brightening the room or covering characters. The 4×4 and 5×5 production renderers call the shared field when loaded, retaining their legacy fallback during initialization. The bedroom shared diffusion method uses the same field. The late pass contains only light and particles, never tent fabric or full fixtures. The clipping path includes the roof, columns, tray and moving door.

Particles drift slowly with fixed seeds, gentle sideways movement and lifetime fades; no simulation state or random generator is changed. Reduced-motion mode keeps the soft static field and omits drifting particles. Off lights and flicker blackouts emit neither field nor dust. Fixture hit targets follow the new housings (including both 5×5 lights) and keep approach points outside the tents.

Run node tools/preview-grow-lights.cjs to produce the four-tier board, day/night tent views, all grow-space contexts, store cards, phone card, 48 animation frames and report.json under review/grow-lights/. The demonstration uses a native vegetative schedule so the night captures show powered lights. Run python tools/animate-grow-lights.py to package those actual runtime frames as a GIF at their original sampled timing.
