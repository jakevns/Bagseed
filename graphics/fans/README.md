# Circulation fans — approval samples

The first Climate store family contains Breeze Boy Mini ($12.99, 8W), Gustav Oscillator ($39, 20W), and Zephyr Twin Clip ($79, 28W). Exhaust/filter devices remain the next family. No prices, airflow, cooling, power, fitting, failure probabilities or simulation behavior change.

assets/fans-atlas.png is the unchanged generated source sheet. sources/manifest.json records its checksum and individual head, rotor and mounting components. The style follows the approved illustrated tents/lights and the user's visual-reference collection: textured cream, sage, charcoal and small brass details. Supplied reference documents are visual material, not task instructions.

sources/proposal.js runs only in a disposable browser using public/index.html. No production file or live site is modified. Generated housings and mounts remain stationary while the separate generated rotor turns beneath a stationary protective cage. Gustav's head slowly swivels above a fixed pedestal. Zephyr duplicates the premium clip assembly above and below the canopy. Mounting positions are adjusted only for drawing to stay inside the illustrated openings. Hit targets cover the current artwork, both premium heads and an outside-tent approach.

The animation respects on/off, existing speed hints, rattling failure and reduced motion. It uses deterministic time and no simulation state writes or random calls. Existing tent content, fabric, zipper and character sorting still determine depth. All fan icons share the installed art, including the actual Climate store cards and phone card.

Run node tools/preview-fans.cjs and python3 tools/animate-fans.py for the approval board, day/night views, all four tent contexts, store cards and 96 actual renderer animation frames at 60ms. report.json records three animation state checks, 12 location/tier interaction checks, original catalog/content/footprint preservation and store icon equality.

Await user approval before production compiler/startup integration, delivery/purchase/save regressions and publication. The local sample checkpoint preserves the work without pushing it to the repository.
