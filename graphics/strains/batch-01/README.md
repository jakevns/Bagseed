# Archived whole-plant concepts

Status: concept study, paused by the user in favor of a single-strain growth-system design. These assets and the fixed-stage prototype are **not included in the production build**.

Porchlight, Velvet Underbrush and Pixel Punch each have 15 painted objects: the 13 stage concepts plus two male flowering variants. PNG sources remain unchanged; runtime WebPs decode to identical RGBA pixels. Crops/anchors are metadata. The experimental renderer scales stage silhouettes and uses a rooted row-sway, but it falls back to native art for training, pruning, staking, mutations and diagnostic states. It is not the proposed production solution.

The approved-looking palette/anatomy direction is retained for reference. See [the Porchlight growth plan](../../../docs/graphics/porchlight-growth-plan.md) for the audit and proposed attached-organ renderer. Generate archived study previews with `node tools/preview-strain-concepts.cjs`; this injects the draft into a disposable browser page and does not change `public/index.html`. Wind PNG sequences are local intermediates excluded from Git; the GIF is retained.
