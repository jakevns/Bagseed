# Air conditioner artwork samples

Awaiting user approval. Includes both existing AC tiers: Rattlebox Compact AC ($139, 300W), and Polar Pal Digital AC ($289, 250W). Cream enamel, sage panels and brass controls match the approved heater family. Mini-splits remain a separate item family.

The original generated transparent PNG is retained unchanged. The fingerprinted WebP decodes to identical RGBA pixels; compile-time checks verify source, runtime and public asset checksums. Crop proportions stay fixed at all locations. Both remain in the approved bedroom station between the jug and heater; grow-room mount anchors remain native. Store, delivery and inventory use matching fixed icons. Startup waits for the new artwork, including a useful error state if it cannot load.

Air movement follows the individual installed AC's actual native cooling activity, including power, thermostat standby, icing, outage and room breakers. A cooling unit elsewhere cannot animate an idle unit. LOW/HIGH affect the delicate breeze strength. Reduced motion removes air movement; powered digital standby retains the live target. Existing night-light helpers add small powered mint indicator/display halos and restrained brass button highlights in the ordinary object layer before foreground occluders. No cold fog or particles are baked into the sprites.

No prices, cooling rules, ownership, power calculations, targeting controls, saves, plants or placement anchors change. Commands: `npm run build:bedroom`, `npm run check`, `node tools/preview-air-conditioners.cjs`, `python3 tools/animate-air-conditioners.py`, and `node --test --test-concurrency=1 tests/air-conditioners.test.cjs tests/room-climate.test.cjs`. Review pictures and runtime validation are in ../../review/air-conditioners. The purchase test exercises both tiers, delivery matching, fitting, controls, plants, save/reload and missing-art startup failure. The preview exercises both tiers at all four locations and cooling/standby/off/ice/outage/reduced-motion behavior in the actual public/index.html.
