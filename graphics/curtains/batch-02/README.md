# Curtain batch 02 — approved and integrated

Exactly two sets: Floral Curtains (`floral`, $18) and Sheer Curtains (`sheer`, $14), the next existing catalog choices after approved Basic/Blackout. The user requested two sets per batch, including animations and store artwork, with pictures for approval before pushing. They approved this pair, authorized the push, and asked for more noticeable motion on both this and the previously pushed pair. Floral uses warm cream cotton printed with small rose-and-sage flowers; Sheer uses translucent ivory voile with looser hem movement. The approved first curtain atlas and sage/cream/oak bedroom were used as visual references.

`assets/curtains-atlas.png` is the original generated transparent image, retained without editing. SHA-256, dimensions and registered source rectangles are in `sources/manifest.json`. Each source rectangle is fitted into a 72×61 logical display frame with its original proportions intact. The rod stays opaque and fixed. Cloth below the mounting strip uses the recorded opacity: Floral 1, Sheer .62, providing actual visibility of the live window through the fabric. The Floral print moves with the cloth. Both sets sway gently in calm weather, more strongly in Windy weather, and remain still in reduced-motion mode; Sheer has a higher motion multiplier. The same art and opacity are used in static store previews.

Both production builders now append this approved module after Batch 01. Metadata records `curtains-batch-02` and four completed sets.
