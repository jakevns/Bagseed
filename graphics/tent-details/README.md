# Controller, grow camera and drying artwork samples

Awaiting user approval. Updates the single Canopy Brain Controller tier ($159, 4W), PeekLeaf Mini Grow Cam ($45), and shared drying status tag. The generated transparent source PNG is preserved unchanged. The fingerprinted runtime WebP decodes to identical RGBA pixels; compilation verifies source/runtime/public checksums and valid crops. Startup waits for this artwork and handles missing assets through the existing loading error screen.

The controller retains its approved exterior header positions and native 9×11 logical envelope, including the existing per-tent transforms and click/approach targets. Its art fits within that box with preserved aspect ratio. The screen reads the actual local environment and native grow/dry/idle state. Powered-off, outage and breaker states have no display/glow. Buttons and indicators use source-aligned small night halos in the ordinary draw pass. The old duplicate glow coordinates were removed from the header wrapper; all controller lighting follows the new art. Reduced motion keeps the small status glow steady. Reading the screen never calls controllerTick or changes targets.

The grow-camera artwork is shared by the store, delivery, empty-camera app card and tent menus. It remains a UI image rather than a new physical room object. Live feeds, mounting/unclipping, camera inventory, prices, access rules and remote viewing restrictions remain native. The camera image retains its shape at all canvas sizes.

The matte drying tag retains the native 16×14 logical envelope and all plant click targets. It includes live temperature/humidity, the existing in-range colors, progress, ready/check states and mold warning. The herb illustration and stitched border are static; percentage and warning use real plant state. Reduced motion keeps a warning visible rather than blinking. Outdoor and greenhouse status signs use the same tag, reading shed conditions when the native remote-drying flag is present. No game targets, drying rate, risk, yield or automation behavior changes.

Rebuild with `npm run build:bedroom`; verify with `npm run check`. `node tools/preview-tent-details.cjs` captures actual public/index.html artwork, eight open/closed header cases, store/menu consistency and healthy/warning/ready tags. `node --test --test-concurrency=1 tests/tent-details.test.cjs tests/sensors.test.cjs tests/starter-tent.test.cjs` checks real purchases, matching delivery, controller automation/power, camera access/mount/unclip, dry-state readings, shed tags, saved state and existing sensor/tent behavior. Samples and validation reports are in ../../review/tent-details.
