# Pineapple Express dedicated components

User-approved production artwork. Native line `cl_pineexpress`. Sunny lime hybrid fans / warm tapered flowers and amber stigmas. Exact approved source and full-cycle/wind checkpoint: `review/strain-batch-13/`.

Sixteen organs use the shared connected renderer, retaining expansion, pruning, supports, stress, mutations and wind. Compatible living saves upgrade artwork without changing seeds, traits, genomes or height; historical photos remain pinned. Rebuild using `python3 tools/compile-plant-components.py pineexpress` and `npm run build:bedroom`.
