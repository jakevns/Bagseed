# Super Lemon Haze dedicated components

User-approved production artwork. Native line `cl_slh`. Fine lime fans / pointed yellow-green flowers and golden stigmas. Exact approved source and full-cycle/wind checkpoint: `review/strain-batch-12/`.

Sixteen organs use the shared connected renderer, retaining expansion, pruning, supports, stress, mutations and wind. Compatible living saves upgrade artwork without changing seeds, traits, genomes or height; historical photos remain pinned. Rebuild using `python3 tools/compile-plant-components.py slh` and `npm run build:bedroom`.
