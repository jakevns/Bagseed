# Trainwreck dedicated components

User-approved production artwork, native line `cl_trainwreck`. Angular narrow lime fans / dense pointed green flower clusters. Golden fan senescence / frosted green bracts and copper stigmas.

Sixteen original organs preserve connected growth, graded flowers, pruning, supports, stress, mutations and root-fixed wind. Compatible living saves upgrade without changing genetics, traits, seed or height; historical photos stay pinned. Exact approved source and cycle/animation checkpoint: `review/strain-batch-11/`. Rebuild with `python3 tools/compile-plant-components.py trainwreck`, then `npm run build:bedroom`.
