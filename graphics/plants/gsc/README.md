# GSC dedicated components

User-approved production artwork. Native line `cl_gsc`. Sage-blue hybrid fans / dense plum and olive resinous bracts. Exact approved source and full-cycle/wind checkpoint: `review/strain-batch-13/`.

Sixteen organs use the shared connected renderer, retaining expansion, pruning, supports, stress, mutations and wind. Compatible living saves upgrade artwork without changing seeds, traits, genomes or height; historical photos remain pinned. Rebuild using `python3 tools/compile-plant-components.py gsc` and `npm run build:bedroom`.
