# Triple Whorl components

Status: **user-approved gameplay implementation for production**.

Radial-open and offset-rear forms use three independent fans at a common node, with three primary branch origins at developed interior nodes. One fan/branch is foreshortened behind the front pair. The juvenile third true leaf is distinct from the cotyledons. New painted node collars emphasize the shared attachment. Leaflet anatomy remains the inherited leaf kit; this arrangement does not imply triploidy.

The structural layer is independent of leaf shape, vascular/variegated tissue, chlorophyll and female-stigma layers. The original strain leaf and flower kit identities remain pinned in the saved visual recipe. Both forms derive deterministically from the existing saved art seed and expressed foliage; clones retain the form. No mutation genes, inheritance probabilities, yield/speed/mold statistics or catalog entries were changed. The existing growth, supports, wind, stress and canopy cleanup systems remain in use.

Original generated PNGs live under `assets/`; the compiler registers attachment geometry and losslessly encodes RGBA-exact WebP with SHA-256 checks. Published atlases live under `public/assets/plants/mutations/whorl/`. The normal bedroom builder retains the new `public/assets/embedded/` image pipeline. Do not edit generated HTML or re-embed image data by hand. All three new atlases participate in startup readiness.
