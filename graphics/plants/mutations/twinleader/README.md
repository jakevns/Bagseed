# Twin Leader components

Status: **user-approved gameplay implementation for production**.

Open-V and upright-V forms share one rooted trunk. The fork emerges progressively after the third node; each leading stem carries connected leaves, smaller branch buds and a terminal flower. Topping a Twin Leader displays four connected terminal tips while preserving both original leader parents. New fork junction art follows the existing skeleton.

The structural layer is independent of leaf shape, vascular/variegated tissue, chlorophyll and female-stigma layers. The original strain leaf and flower kit identities remain pinned in the saved visual recipe. Both forms derive deterministically from the existing saved art seed and expressed foliage; clones retain the form. No mutation genes, inheritance probabilities, yield/speed/mold statistics or catalog entries were changed. The existing growth, supports, wind, stress and canopy cleanup systems remain in use.

Original generated PNGs live under `assets/`; the compiler registers attachment geometry and losslessly encodes RGBA-exact WebP with SHA-256 checks. Published atlases live under `public/assets/plants/mutations/twinleader/`. The normal bedroom builder retains the new `public/assets/embedded/` image pipeline. Do not edit generated HTML or re-embed image data by hand. All three new atlases participate in startup readiness.
