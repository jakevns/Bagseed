# Skunk #1 dedicated components

Status: user-approved production artwork, 2026-10-19. Native line `cl_skunk1`.

Sixteen original painted organs supply forest-green hybrid fans, elongated olive female flowers, ivory-to-amber stigmas and resinous sugar leaves. Natural finishing color follows the existing golden phenotype. No native trait, growth, yield, climate or breeding values change. Source PNGs are retained; the compiler measures isolated nonoverlapping crops and verifies exact RGBA-equivalent lossless WebP.

The existing connected renderer handles full growth, wind, fixed roots, reduced motion, supports, training, stress, graded branch/popcorn buds, cleanup and all fifteen mutations. Living old saves receive compatible new parts at create/load/save boundaries without rerolling identity seeds, traits, genomes or physical height. Incompatible expressed traits keep their donor parts; historical photo recipes remain pinned.
