# Starter pop-up tent — artwork proposal

Awaiting user approval. This batch covers only the existing starter pop-up frame: the included Budget shell and the $35 Standard replacement shell. Larger tents and their Pro/Premium upgrades belong to later batches. No equipment artwork changes in this proposal.

The two original generated atlases are retained unchanged in assets/. Each contains an empty open shell and a zipped closed shell. Their checksums, technical crop bounds and original dimensions are recorded in sources/manifest.json. Charcoal canvas, quiet olive binding, warm silver lining and painterly outlines follow the approved bedroom and storage artwork. Budget has faded fabric, repaired corners and a simple silver pull; Standard has reinforced seams and brass pulls.

Run `node tools/preview-starter-tent.cjs` for the sample board, actual bedroom views and desktop/mobile LeafCart Standard-shell card. The helper opens public/index.html and injects sample drawing functions into an isolated browser context. It preserves live plant and equipment drawing and verifies unchanged interaction targets, catalog and bedroom footprints. Production HTML, builders and original source game remain untouched.

These are still-image approval samples. Final integration must implement the existing zip transition with separate fabric/foreground layers, preserve shell wear/leak indicators, and cover startup readiness, store/package/inventory art, shell fitting, save reload and reduced motion. The proposal does not claim those production checks are complete.
