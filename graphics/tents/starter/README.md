# Starter pop-up tent — artwork proposal

Awaiting user approval. This batch covers only the existing starter pop-up frame: the included Budget shell and the $35 Standard replacement shell. Larger tents and their Pro/Premium upgrades belong to later batches. No equipment artwork changes in this proposal.

The two original generated atlases are retained unchanged in assets/. Each contains an empty open shell and a zipped closed shell. Their checksums, technical crop bounds and original dimensions are recorded in sources/manifest.json. Charcoal canvas, quiet olive binding, warm silver lining and painterly outlines follow the approved bedroom and storage artwork. Budget has faded fabric, repaired corners and a simple silver pull; Standard has reinforced seams and brass pulls.

Run `node tools/preview-starter-tent.cjs` for the sample board, corrected layering closeup, actual bedroom views and desktop/mobile LeafCart Standard-shell card. The helper opens public/index.html and injects sample drawing functions into an isolated browser context. It preserves live plant and equipment drawing, equipment/shell interaction targets, catalog and bedroom footprints. Production HTML, builders and original source game remain untouched.

The user's requested layering correction is implemented in the proposal: render the empty shell behind the contents, clip the contents to the rounded opening, then composite the original roof/rolled flap, side edging and front tray as a foreground mask. Move the slot drawing and its click target upward by 10 logical pixels so the pot rests behind the front tray. Logical plant/slot records and grow behavior stay unchanged. The room preview also composites the foreground over the native late light-beam pass. Production integration must account for ambient tint and that late pass rather than leaving beam effects over the frame. Bright pixel probes verify roof/light and tray/pot occlusion while keeping the visible light and pot bodies present across both shells, four light drawings and three pot drawings (24 combinations).

These are still-image approval samples. Final integration must implement the existing zip transition with separate fabric/foreground layers, preserve shell wear/leak indicators, and cover startup readiness, store/package/inventory art, shell fitting, save reload and reduced motion. The proposal does not claim those production checks are complete.
