# Starter pop-up tent — approved

The user approved the drawings and corrected foreground layering, then authorized publication on 2026-10-16. This release covers only the existing starter pop-up frame: the included Budget shell and the $35 Standard replacement shell. The following approved 2×2 release also narrows this frame to 54×90 while preserving its height and single plant slot. Equipment retains its own live renderer.

The two original generated atlases are retained unchanged in assets/. Each contains an empty open shell and a zipped closed shell. Their checksums, technical crop bounds and original dimensions are recorded in sources/manifest.json. Charcoal canvas, quiet olive binding, warm silver lining and painterly outlines follow the approved bedroom and storage artwork. Budget has faded fabric, repaired corners and a simple silver pull; Standard has reinforced seams and brass pulls.

Run `node tools/preview-starter-tent.cjs` or `node --test tests/starter-tent.test.cjs` for production browser checks and actual bedroom/store pictures in review/starter-tent/integration/. The helper uses public/index.html. The approved sample board remains in review/starter-tent/. The helper also retains its original isolated proposal mode for its matching pre-integration base build.

The renderer draws the empty shell behind the live contents, clips contents to the rounded opening, and composites the original roof/rolled flap, sides and tray as a foreground mask. The plant/pot group is drawn at .86 scale with soil anchored at y74, leaving visible liner in front of its base. Click rectangles use the same transform and walk access stays outside. Plant/slot records, growth, equipment and catalog/prices remain intact; source geometry and placement reservations follow the new width. Fabric is drawn before nearby actors; local diffuse lighting replaces the legacy fixed-width beam, and RoomArt.growEffectMasks.closet suppresses that old effect instead of repainting fabric over the player. Ambient tint remains part of the normal scene pass. The door uses nine stepped positions from the existing animation and honors reduced motion. Worn-zipper warnings and drying tags remain; unsupported legacy shell tiers fall back to their existing renderer.

ShellArt.icon shares the same drawing across LeafCart, delivery and unused-shell inventory, and the grow-space icon also uses the new art. BagseedStarterTent.ready is required by the early loading gate. Both graphics build paths include compile-starter-tent.cjs through the bedroom builder; npm run check verifies that the embedded module matches its sources. The original PNGs are preserved; the original preparation script documents the first release; the revised narrow atlas and its lossless WebP runtime copy are recorded in the current manifest.

Production coverage: 24 light/pot/shell layering combinations, 12 interaction cases including drying plants and zipped doors, day/night foreground masks, nine closing frames, opening/reduced motion, wear/drying indicators, desktop/mobile store cards, a real $35 purchase/delivery, shared store/package/inventory art, fitting without changing grow contents, and save/reload. The prototype report and approved pictures are retained separately from the production integration report.
