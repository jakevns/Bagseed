# Approved 5×5 tent release

The user approved and authorized publishing this six-slot GrowHut 5×5 Pro tent ($489, Standard shell included), Pro replacement ($189) and Premium replacement ($339). It remains at x178/y2, 182×142 in the grow room, larger than the approved 132×128 4×4. Catalog names, prices, unlocks, capacity, growth and collision bounds remain unchanged.

assets/tents-atlas.png is the corrected original generated sheet, retained unchanged. sources/manifest.json records its SHA-256, dimensions and six open/closed crops. The lossless WebP has identical decoded RGBA pixels and is served from a fingerprinted public/assets/tents URL. tools/compile-tent5.cjs verifies both source and published asset hashes; BagseedTent5.ready participates in the loading gate. npm run build:bedroom rebuilds public/index.html and preserves the current character/walking payload. npm run check verifies compiled modules and the build.

The renderer draws lining, soft light for two fixtures, clipped independent equipment and six plants, then roof, columns, liner lip and door fabric. Pots are recessed 24 pixels and their centers pulled inward by 10/6/2/−2/−6/−10 pixels to fit the opening. Visual targets follow those offsets while walk destinations stay outside. Logical slot positions are restored after drawing, and native actor/furniture sorting is retained. Fabric is never repainted after actors. Native 380 ms/nine-step zipper motion, reduced motion, external climate/controller equipment and wear/drying tags remain.

The broad four-strap doorway, sage Standard binding, moss Pro reinforcement and brass/diamond Premium construction match the approved family. LeafCart, delivery, inventory and grow-space icons share the same art. The published 4×4 remains visible alongside it in full-room captures.

node tools/preview-tents-5x5.cjs captures the shipped build, without injected proposals, into review/tents-5x5/. python tools/animate-tents-5x5.py packages its runtime captures into a slowed review GIF; game timing is unchanged. tests/tent5.test.cjs exercises all purchases and shell fitting, content preservation, collision/approach bounds, save/reload and a deliberately failed external image that must keep the loading cover visible. The starter, 4×4 and player-depth suites protect prior releases. sources/proposal.js remains as the original approved sample implementation.
