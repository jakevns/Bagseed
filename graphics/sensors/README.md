Approved for publication on 2026-10-17. Includes the free paper note for the existing hand-reading option, Probably-A-Thermometer ($6.99), TrueRead Hygrometer ($24.99), and Canopy Sentinel ($89). No new products or changes to prices, noise, failure chances, installation, controls or climate calculations.

The unchanged generated PNG is retained in assets. The fingerprinted runtime WebP has identical decoded RGBA pixels; the compiler checks source/runtime/public hashes and crop bounds. Sensor decoding participates in the startup readiness gate.

The renderer replaces only Gear.sensor and its store/inventory/delivery icon. Each design preserves the source artwork aspect ratio and uses one fixed physical size across every tent. The common mount scale is 0.72; sensor centers and top mounting anchors remain at the finalized positions. The adjacent brain controller retains its previous size. Review headers use identical world-space crops and zoom instead of stretching to fit tent-dependent rectangles. All four designs remain visible with zipped doors. The paper has no invented readings. The analog needle and numeric temperature use the supplied environment. Digital devices show temperature and humidity. The smart sensor plots the existing saved climate log, without generating history or advancing the simulation. Rendering never samples game RNG.
