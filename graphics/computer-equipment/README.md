# Computer equipment — awaiting artwork approval

This proposal updates the existing Old Laptop, Used Desktop and Dual-Monitor Rig. All four keyboard choices, three desk mats and five monitor wallpapers retain their original option IDs and prices. No new equipment choices are added. Cameras and chairs are later batches.

Source PNGs are retained in assets. The manifest records original atlas dimensions and hashes, crop bounds, and normalized display rectangles. The renderer keeps wallpaper, climate history, power indicators and RGB effects separate from the painted hardware. It shares the same artwork across room, store, style and package previews.

Run `node tools/preview-computer-equipment.cjs` to load public/index.html and inject the proposal into the preview browser. Production builds are unchanged until the user approves the pictures. Save this proposal in a local commit; do not push it before approval.
