# Combined heating/cooling samples

Approved by the user, including both combined units and automatic return of separate room heaters/ACs to Unused gear. Both store tiers are illustrated: Breeze Bridge Mini-Split ($549, 220W) and Canopy Climate Smart HVAC ($849, 210W). Existing wall anchors remain beside the window; no other furniture moves. Each crop keeps its original aspect ratio and width 26 across locations. The source PNG is unchanged, and its fingerprinted WebP decodes to identical RGBA pixels. Compilers verify all checksums. Startup waits for the artwork, with a retry/error state when unavailable.

The native individual HVAC activity determines heating, cooling and standby. Warm air uses amber lines/status; cool air uses mint lines/status. Both target temperatures remain visible in powered standby. Powered-off units have no airflow. Reduced motion keeps static artwork and indicators without air movement. Matching fixed store, inventory and delivery icons never inherit world animation.

Installing either tier automatically returns installed separate heaters and ACs from all grow locations in the same room to Unused gear. IDs, condition, price history and other metadata remain intact. Older saves receive the same idempotent cleanup through Gear115.sync, after existing installed instances have been recovered. Separate devices cannot be reinstalled in a room while a combined unit is fitted; remove the combined unit to use them again. Other rooms retain their installed gear. Same-slot combined upgrades retain the old unit as unused gear. Native prices, heat/cool calculations, targets, plant data and unrelated equipment remain unchanged. Both store descriptions explain replacement before purchase.

Build: `npm run build:bedroom`. Verify: `npm run check`. Integration: `node --test tests/hvac.test.cjs` exercises real purchases/delivery, cross-tent room replacement, item preservation, other rooms, combined upgrades, legacy cleanup, controls at the window, native heat/cool/idle/off, saves, spare reuse and missing-art startup failure. Review: `node tools/preview-hvac.cjs` and `python3 tools/animate-hvac.py` capture actual public/index.html drawings, eight placements, reduced motion, live targets and matching store cards. Pictures, motion samples and validation reports live in ../../review/hvac.
